매일 한국 시간 05–20시 정각에 돈이웃 채널용 한국 재테크 YouTube Short 1개를 만들어 공개 게시한다. 다시 묻지 마라. 초안·일부공개로 머무지 마라.

중복 금지: 같은 채널에 같은 헤드라인은 한 번만. `python -m shorts pick`이 Supabase `youtube.uploads`를 보고 선점한다. 이미 있는 해시는 고르지 마라. 업로드가 끝나면 `record`로 video id를 남겨라.

저장소 루트에서 다음을 그대로 실행한다.

1. `python -m shorts pick --channel 돈이웃` 을 실행하고 stdout의 잡 폴더를 쓴다. pick이 테이블에서 채널별 사용 해시를 확인하고 `picked`로 선점한다. “쓸 헤드라인 없음”이면 중단.
2. 그 폴더의 headline.json만 보고 같은 폴더에 원본 script.json을 직접 작성한다. OpenAI/Gemini 등 외부 LLM HTTP 호출 금지. 헤드라인에 없는 숫자·목표가 금지. 매수/매도/추천 금지. 기사 복제 금지.
   - scenes 4~5개. 훅 + 비트 + 정리. duration 합 50~60초.
   - captions로 문장을 짧게 끊는다. 대본은 화면 자막만.
   - image_prompt는 영어. 글자·로고·실존 인물 얼굴 없음. 세로 9:16.
   - title에는 해시태그를 넣지 않는다. description은 본문 + 빈 줄 + 해시태그. 면책 한 줄. 해시태그에 #돈이웃 #쇼츠 #shorts 포함.
3. 장면마다 Cursor GenerateImage, aspect_ratio 9:16. 결과를 잡 폴더의 scene-01.png … 로 저장. imagegen CLI, OPENAI_API_KEY, GEMINI_API_KEY, FAL_KEY 금지.
4. `python -m shorts run --dry-run --dir <잡폴더>` 로 렌더. ffmpeg 1080x1920 Ken Burns + 자막 + 로컬 무료 BGM. TTS 없음. 유튜브 음원 yt-dlp 금지. ffmpeg 없으면 중단. 성공 시 상태가 `rendered`로 기록된다.
5. video.mp4가 생기면 돈이웃 YouTube 채널(UCHUxp49IFZlHHCcg_LnL66A) Studio Shorts에 공개 게시한다. 제목은 script title에서 해시태그 제거. 설명은 본문 + 빈 줄 + 해시태그. 아동용 아님. 공개 상태 PUBLIC 후 게시. 목록 맨 위 제목과 video id를 확인한다.
6. `python -m shorts record --dir <잡폴더> --status uploaded --video-id <id>` 로 `youtube.uploads`에 완료 행을 넣는다. 이 단계 없이 끝내지 마라.
7. 실패 시 로그만 남기고 중단. picked/rendered/uploaded 헤드라인은 다시 pick하지 마라. offscn 영상을 돈이웃에 올리지 마라.
