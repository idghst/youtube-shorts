매일 한국 시간 05–20시 정각에 돈이웃 채널용 한국 재테크 YouTube Short 1개를 만들어 공개 게시한다. 다시 묻지 마라. 초안·일부공개로 머무지 마라.

중복 금지: 같은 채널에 같은 헤드라인·비슷한 주제는 한 번만. pick이 Supabase `youtube.uploads` 해시와 이전 제목을 보고 선점한다. 업로드가 끝나면 `record`로 video id를 남겨라.

저장소 루트에서 이 순서로 실행한다.

1. 이전 주제 + 선정: `python -m shorts pick --channel 돈이웃`. stdout 잡 폴더. “쓸 헤드라인 없음”이면 중단. `used-topics.json`을 읽는다.
2. 대본: headline.json + used-topics.json만 보고 script.json의 scenes를 먼저 쓴다. 외부 LLM HTTP 금지. 헤드라인에 없는 숫자·목표가 금지. 매수/매도/추천 금지. 기사 복제 금지.
   - scenes 4~5개. duration 합 50~60초. captions 장면당 2개 이상. 화면 자막만.
   - 해요체·짧은 구어·질문. 습니다 연속 금지. 메타 자막·면책 장면·「다시 살펴볼 시점」 금지.
   - image_prompt는 Grok Imagine 자연어 영어 2~3문장. 9:16, 하단 1/3 비움. 걱정하는 시니어(사람) 필수. 정물만·사람 없음 금지. 한글·숫자·로고·실존 유명인 얼굴 없음. 필드 나열·키워드 나열 금지.
3. 제목: 대본 본 뒤. 해시태그 없음. 첫 자막 복붙 금지. 입니다/습니다 금지.
4. 설명: 본문만. 제목 복붙 금지. 해시태그·면책 넣지 말 것.
5. 해시태그: `#돈이웃 #쇼츠 #shorts` + 주제 태그 2개 이상. 5~10개.
6. 이미지: `image_prompt`를 GenerateImage 설명으로 씀. aspect_ratio 9:16 → scene-01.png …. imagegen CLI, OPENAI_API_KEY, GEMINI_API_KEY, FAL_KEY 금지.
7. 영상: `python -m shorts run --dry-run --dir <잡폴더>`. ffmpeg 1080x1920 Ken Burns + 자막 + 로컬 무료 BGM. TTS 없음. ffmpeg 없으면 중단.
8. 업로드: video.mp4가 생기면 돈이웃 YouTube 채널(UCHUxp49IFZlHHCcg_LnL66A) Studio Shorts에 공개 게시. 하단 독의 크롬 아이콘을 눌러 연 뒤, 열린 크롬 창에서 `navigate`로 Studio Shorts URL로 이동. 제목은 script title(해시태그 없음). 설명은 본문 + 빈 줄 + 해시태그. 아동용 아님. PUBLIC 후 게시.
9. 기록: `python -m shorts record --dir <잡폴더> --status uploaded --video-id <id>`. 이 단계 없이 끝내지 마라.

실패 시 로그만 남기고 중단. picked/rendered/uploaded 헤드라인은 다시 pick하지 마라. offscn 영상을 돈이웃에 올리지 마라.
