매일 한국 시간 05–20시 정각에 돈이웃 채널용 한국 재테크 YouTube Short 1개를 만들어 공개 게시한다. 다시 묻지 마라. 초안·일부공개로 머무지 마라.

중복 금지: 같은 채널에 같은 헤드라인·비슷한 주제는 한 번만. pick이 Supabase `youtube.uploads` 해시와 이전 제목을 보고 선점한다. 업로드가 끝나면 `record`로 video id를 남겨라.

저장소 루트에서 이 순서로 실행한다.

1. 이전 주제 + 선정: `.venv/bin/python -m shorts pick --channel 돈이웃`. stdout 잡 폴더. “쓸 헤드라인 없음”이면 중단. `used-topics.json`을 읽는다.
2. 이 쇼츠 화풍 하나: `style.anchor`·`style.face`·`style.wardrobe`를 먼저 쓴다. 쇼츠마다 달라도 됨. 한 쇼츠 안 컷은 같은 얼굴·나이·옷·마을·빛. 스토리가 이어지게. 얼굴이 젊어지거나 늙으면 다시 생성. 손·발이 같은 쪽에 두세 개면 다시 생성.
3. 대본: headline.json + used-topics.json만 보고 script.json의 scenes를 먼저 쓴다. 외부 LLM HTTP 금지. 헤드라인에 없는 숫자·목표가 금지. 매수/매도/추천 금지. 기사 복제 금지.
   - scenes 4~5개. 장면 duration은 3초 배수, 합 48~60초. 권장 60초. captions 장면당 2개 이상. 화면 자막만.
   - 장면마다 `beats` = duration/3. 비트마다 image_prompt 1개. 60초면 beat 20개.
   - 첫 자막은 훅(질문·덜 끝난 말). 마지막은 내 돈(월급·이자·대출·연금).
   - 해요체·짧은 구어·질문. 습니다 연속 금지. 메타 자막·면책 장면 금지.
   - 모든 beat image_prompt에 style.anchor·face·wardrobe와 `exactly two hands and two feet, no extra limbs`를 그대로 넣는다. 장편 애니 화풍. 실사 사람·망가/치비 금지. 줌 인 금지. 한글·숫자·로고·실존 유명인 없음. 저작권 캐릭터 금지.
4. 제목: 대본 본 뒤. 해시태그 없음. 숫자 또는 물음표. 첫 자막 복붙 금지. 입니다/습니다 금지.
5. 설명: 본문만. 제목 복붙 금지. 해시태그·면책 넣지 말 것.
6. 해시태그: `#돈이웃 #쇼츠 #shorts` + 주제 태그 2개 이상. 5~10개.
7. 이미지: GenerateImage 9:16 → beat-01.png … beat-20.png. 3초당 1장. 동영상 클립은 만들지 말 것. 직전 비트(+ beat-01)를 레퍼런스로 얼굴·옷·분위기를 고정. imagegen CLI, OPENAI_API_KEY, GEMINI_API_KEY, FAL_KEY 금지.
8. 영상: `.venv/bin/python -m shorts run --dry-run --dir <잡폴더>`. ffmpeg 1080x1920 맞춤(확대·crop·검정 레터박스 없음) + 외곽선 자막 + 로컬 무료 BGM. TTS 없음. ffmpeg 없으면 중단.
9. 업로드: video.mp4가 생기면 돈이웃 YouTube 채널(UCHUxp49IFZlHHCcg_LnL66A) Studio Shorts에 공개 게시. 하단 독의 크롬 아이콘을 눌러 연 뒤, 열린 크롬 창에서 `navigate`로 Studio Shorts URL로 이동. `.venv/bin/python -m shorts meta --dir <잡폴더>` 출력의 title / description / hashtags / tags를 그대로 쓴다. 제목은 meta.title(해시태그 없음). 설명은 meta.description 전체. 아동용 아님. **설명에 #를 넣은 것만으로 끝내지 마라.** 세부정보에서 `자세히`(또는 `자세히 보기`)를 누르고 **아래로 스크롤**한 뒤, **해시태그** 칸에 meta.hashtags(칩 5개 이상)와 **태그** 칸에 meta.tags(10개 이상, 돈이웃/쇼츠/shorts 제외)를 넣는다. 해시태그 칸이 비면 `다음` 금지. thumb.png를 커스텀 썸네일로 올린다. PUBLIC 후 게시.
10. 기록: `.venv/bin/python -m shorts record --dir <잡폴더> --status uploaded --video-id <id>`. 이 단계 없이 끝내지 마라.

실패 시 로그만 남기고 중단. picked/rendered/uploaded 헤드라인은 다시 pick하지 마라. offscn 영상을 돈이웃에 올리지 마라.
